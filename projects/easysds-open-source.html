EasySDS Open Source

Overview

EasySDS Open Source is a free version of EasySDS that anyone can use without an account: open the page and start making labels. It covers the label engine, a local chemical library, and sharing. It leaves out everything that needs a backend: accounts, approvals, the admin console, the blacklist, and history.

I adapted the EasySDS label engine into a standalone version that runs from a single index.html file with no server.

Key Details

  • Same label engine as EasySDS: full labels and stickers (3×4 and 4×5 OL475LP), 4-up sheets and 1-up test prints, on Letter, A4, and SRA3 paper. Includes NFPA and HMIS ratings, automatic Additional PPE, and truncation warnings.
  • Chemical library: searchable chemical list with a duplicate-name warning, plus favorites.
  • No account: chemicals save immediately to the browser's localStorage, with optional Google Drive sync using your own OAuth Client ID.
  • Sharing: export and import labels and libraries as JSON, or save a copy of the page with your library built in.
  • Your branding: upload a company logo, stored in the browser.
  • One file: the whole app is a single index.html.

Overview

EasySDS started during my Summer 2026 Mechanical Engineering internship at Rhenus Automotive in Salem, VA, as an automated chemical labeling compliance tool that enforces required GHS/OSHA fields. It cut per-label cost to under $1 and processing time by 90%.

It is now a Firebase-backed web app that generates OSHA HazCom 2012 and GHS compliant chemical labels, with facility-gated login, an approval queue, and multiple print formats.

My Role

I architected the Firestore data model and admin tooling for per-facility chemical inventories. I implemented it with Claude Code and reviewed the generated code against GHS field requirements.

The app is two pages: a label tool for workers and an admin console for engineering managers. Both run in the browser and are hosted on GitHub Pages, with Firebase handling sign-in and data.

Key Details

  • Compliance: generates labels to OSHA HazCom 2012 and GHS, enforcing the required fields: product identifier, signal word, GHS pictograms, hazard and precautionary statements, first aid, and supplier contact. Labels can also carry NFPA 704 and HMIS ratings.
  • Live preview and print formats: the label updates as you type and prints to 3×4 in, 4×5 in, Letter, A4, SRA3, and 4-up sheet layouts.
  • Access and workflow: facility-gated login with worker accounts. New chemicals go into an approval queue, and admins approve or reject them with an optional reason sent to the submitter.
  • Data model: Firestore with a chemical library per facility, company-wide chemicals, a chemical blacklist checked on entry, and an activity log of every approval, rejection, and change.
  • Admin console: manage facilities, invite and deactivate workers, bulk-load chemicals and blacklist entries from CSV, transfer chemicals between facilities, and upload facility logos.
  • Print validation: output validated on BS 5609 certified vinyl label stock with a color laser print workflow, documented as a standard work instruction.
  • Impact: per-label cost under $1 and a 90% reduction in processing time.

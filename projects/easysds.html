Overview

EasySDS started during my Summer 2026 Mechanical Engineering internship at Rhenus Automotive in Salem, VA, as an automated chemical labeling compliance tool that enforces required GHS/OSHA fields. It cut per-label cost to under $1 and processing time by 90%.

It is now a Firebase-backed web app that generates OSHA HazCom 2012 and GHS compliant chemical labels, with facility-gated login, an approval queue, and multiple print formats.

There is also a free, no-account version: EasySDS Open Source keeps the same label engine and leaves out everything that needs a backend.

My Role

I architected the Firestore data model and admin tooling for per-facility chemical inventories. I implemented it with Claude Code and reviewed the generated code against GHS field requirements.

Key Details

  • Compliance: generates labels to OSHA HazCom 2012 and GHS, enforcing the required fields.
  • Label engine: full labels and stickers (3×4 and 4×5 OL475LP), 4-up sheets and 1-up test prints, on Letter, A4, and SRA3 paper. Includes NFPA and HMIS ratings, automatic Additional PPE, and truncation warnings.
  • Chemical library: searchable chemical list with a duplicate-name warning, and favorites shared across each facility.
  • Accounts: facility accounts with sign-in, self-registration, and password reset. Each facility's company logo comes from its facility record.
  • Approval workflow: new or edited chemicals go through an approval queue, and only admins can overwrite directly. Printing is blocked for chemicals not in the approved library, and admins can open a label preview from the review screen.
  • Admin console: dashboard, facilities, workers, approvals, company-wide chemicals, a blacklist that blocks saving restricted chemicals, and history. Admins can switch between facilities.
  • Data model: Firestore with admin tooling for per-facility chemical inventories, plus invite emails and client error and event logging.
  • Print validation: output validated on BS 5609 certified vinyl label stock with a color laser print workflow, documented as a standard work instruction.
  • Impact: per-label cost under $1 and a 90% reduction in processing time.
